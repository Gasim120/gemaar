# Project Summary
The **G EMAAR AI** project is an advanced AI-driven web application designed to transform both interior and exterior design. Users can upload images and receive AI-generated redesign suggestions, enabling them to visualize changes before making decisions. The platform includes user authentication, an admin dashboard, subscription plans, and supports both Arabic and English, appealing to a diverse audience. A blog section enhances user engagement and SEO, and a testimonials page showcases customer experiences.

# Project Module Description
The project consists of several functional modules:
- **Authentication**: Manages user login/logout and session management.
- **Design Upload**: Allows users to upload images for redesign.
- **AI Processing**: Utilizes AI to generate design suggestions and transformations.
- **Dashboard**: A workspace for users to manage their designs.
- **Admin Panel**: Provides an overview of user statistics and design management.
- **Multilingual Support**: Full support for Arabic and English languages.
- **Blog Section**: Hosts articles related to design, enhancing SEO and user engagement.
- **Testimonials Page**: Displays customer reviews and ratings to build trust and showcase user satisfaction.

# File Description Inventory
- **app/backend/main.py**: The main entry point for the backend application.
- **app/backend/core/**: Contains core functionalities such as authentication and database configuration.
- **app/backend/models/**: Defines the data models used in the application.
- **app/backend/routers/**: Manages API endpoints.
- **app/backend/services/**: Contains business logic related to designs and subscriptions.
- **app/frontend/src/**: Contains the main React application code including components, pages, and utilities.
- **app/frontend/public/**: Contains static assets like images and icons.
- **app/frontend/package.json**: Manages frontend dependencies and scripts.
- **app/frontend/src/pages/blog/**: Contains blog listing and detail pages.
- **app/frontend/src/pages/testimonials/**: Contains the testimonials page.
- **app/frontend/src/lib/blog.ts**: Library for managing blog functionality.
- **app/frontend/src/lib/i18n.ts**: Handles internationalization for multiple languages.
- **app/frontend/src/index.css**: Contains CSS styles, including modifications to hide the scrollbar on mobile devices.
- **app/frontend/prerender/**: Configuration for prerendering blog pages.

# Technology Stack
- **Backend**: Python, FastAPI
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: SQLAlchemy for ORM with a SQL database
- **AI Services**: Integration with AI models for image processing
- **Deployment**: Docker for containerization
- **SEO**: Blog section with SEO-optimized content

# Usage
To get started with the project:
1. **Install Dependencies**:
   - For backend: Navigate to `app/backend` and install dependencies.
   - For frontend: Navigate to `app/frontend` and run the install command.
2. **Build the Frontend**: Run the build command in the frontend directory.
3. **Run the Backend**: Start the backend server using the command in the backend directory.
4. **Access the Blog and Testimonials**: Use the integrated blog and testimonials sections within the frontend.
